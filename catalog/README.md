# Catalog

The downloadable map packages. Each one is `catalog/<id>.json` plus its data parts in `catalog/<id>/`. The apps list every `*.json` here through the GitHub contents API and download the parts each entry points at.

- [docs/country-maps.md](../docs/country-maps.md) is the specification: fields, formats, size limits and what the validator checks.
- [CONTRIBUTING.md](../CONTRIBUTING.md#add-a-country-or-a-region) explains how to build and add a package.
- `node scripts/validate-catalog.mjs` checks every package here.

Everything in this folder is generated by `scripts/maps/build-country.sh`. Do not edit the parts by hand.
