# Catalog (moved)

The map packages moved to [bug-catcher90/blackout-maps-data](https://github.com/bug-catcher90/blackout-maps-data). Add and rebuild packages there; see its [CONTRIBUTING.md](https://github.com/bug-catcher90/blackout-maps-data/blob/main/CONTRIBUTING.md).

The `*.json` files here are frozen copies of the data repository's entries, with part URLs that point at it. They exist only for Android and iOS 1.0, which list this folder through the GitHub contents API. Current apps read `catalog/index.json` in the data repository instead. Do not add packages here. Delete this folder once no 1.0 build is in use.
